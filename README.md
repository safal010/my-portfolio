## 🚀 Featured Projects

### 1. AI Voice Chat Application (Asha)
An AI-powered voice companion for practicing English through real-time, low-latency STT–LLM–TTS conversations, featuring live transcripts and saved conversation history.
- **Tech Stack:** Python, LiveKit Agents, Next.js, TypeScript, LiveKit Cloud, PostgreSQL, Docker

### 2. AI-Powered RAG Chatbot
A full-stack conversational assistant that retrieves relevant context from a custom knowledge base to generate grounded responses and persists chat history.
- **Tech Stack:** React, FastAPI, Python, Gemini, RAG, FAISS, SQLite

### 3. Nepal Heavy Rainfall Prediction
A machine learning forecasting dashboard using a Random Forest Classifier and live Open-Meteo weather data to predict 3-day rainfall and identify heavy-rainfall risk (≥50 mm/day) across six locations in Nepal.
- **Tech Stack:** Python, Pandas, Scikit-learn, Streamlit, Open-Meteo API

## 💻 Run Locally

1. **Clone the repository**
   ```bash
   git clone [https://github.com/safal010/](https://github.com/safal010/)<your-portfolio-repo>.git
   cd <your-portfolio-repo>
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Start the development server**
   ```bash
   npm run dev
   ```
